# TelaFlux Final

Inclui catálogo TMDB, login via TMDB, watchlist sincronizada, detalhes/trailers e permissão para notificações do navegador.

## Rodar
Node.js 18+ → `npm install` → copie `.env.example` para `.env` → defina `TMDB_TOKEN` e `APP_URL` → `npm start`.

O login segue o fluxo oficial de autenticação do TMDB. A watchlist é salva na conta TMDB do usuário quando ele está conectado.
